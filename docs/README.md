# Documentation

The [README](../README.md) is the guide: install, a quick start, every
verb, the configuration grammar, the sets, the guard hook and what a fix
costs. `ctrm --help` and `ctrm <verb> --help` are the command reference.
These pages go further:

| page | for |
|---|---|
| [FAQ.md](FAQ.md) | questions a first run raises, and the messages behind them |
| [COMPARISON.md](COMPARISON.md) | anti-trojan-source, editorconfig-checker, a grep one-liner, and when not to use `ctrm` |
| [JSON.md](JSON.md) | the `--format json` contract: every key, unit and enum, and when the schema number changes |
| [MEMORY.md](MEMORY.md) | how much RAM a run uses and why, measured |
| [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) | the dependencies, the vendored data, and what a redistributor owes |
| [LLM-DISCLAIMER.md](LLM-DISCLAIMER.md) | how the tool was built, and how to check that for yourself |

For contributors: [CONTRIBUTING.md](../CONTRIBUTING.md) for the quick path,
[AGENTS.md](../AGENTS.md) for the full rules, and [SPEC.md](../SPEC.md) for
what must stay true. Changes per release are in
[CHANGELOG.md](../CHANGELOG.md); security reports go through
[SECURITY.md](../SECURITY.md).
